# Round 7 audit: export, canvas options, architecture, library (frames 42, 43, 46–49)

Stage 1 of `docs/ROUND7_TODO.md`. This was a read-only audit: no source files were changed.

**How it was tested:** the live app at http://localhost:5330/?demo=1 ("Continue offline", "Skip"), driven by puppeteer-core and Edge with a real mouse, touch and keyboard. Desktop runs used 1440×900; phone runs used 412×915 with touch. Both Lamplight and Paper themes were checked, plus RTL Arabic. Test documents: "Payments platform" (architecture), "Backprop study board" (canvas), "Study plan — November" (whiteboard, with frames drawn using the Frame tool), a Mermaid job, and new diagrams from the chooser. Every export was downloaded and its file checked: PNG size, PDF page count (pdf-lib), ZIP entries, SVG contents. AI responses were mocked at `/ai/visual/*` so the describe, diff and review screens could be tested offline.

**Screenshots:** `design/verify/r7/audit/arch-canvas-export/<ID>-app.png` (extra states use suffixes such as `-paper`, `-rtl`, `-held`, `-applied`).

## Verified working (no gap)
- **Export dialog shell (42A–D, 42F, 42I, 43C):** the layout, preset/scope/format/look/content blocks and the pinned Download on phone match closely.
- **Whiteboard frame exports:** Frames scope with 1–4 frames; PDF one page per frame gives a 4-page PDF (960×540 pt); single page gives 1 page; PNG and SVG frames give a ZIP of per-frame files; the "Rendering 4 frames… 4 of 4" state shows. Whole-board PNG, transparent background and Source `.excalidraw` all download.
- **Canvas formats:** PNG (1976×1044 at 2×), JPEG, WebP, SVG (scene embedded), PDF (1 page), `.canvas`, Markdown and Mermaid all download. The Copy menu lists Copy PNG / SVG / source / as Markdown / link.
- **Mermaid job (42D):** the SVG downloads (vector, with text).
- **Code ↔ canvas sync (46C):** typing a new `Cache [icon: cache]` line adds the node within about 10 ms. Existing nodes keep their positions (only the parent groups re-fit). Ctrl+Z removes the node again.
- **Code hover (46G):** hovering line 9 highlights DB; hovering a node lights its code line.
- **Syntax error (46H):** gutter dot, wavy underline, top banner and footer appear, and the canvas keeps the last valid diagram.
- **Layout (48A):** popover options, ghost preview, Apply ("Layout applied" + Undo), and Ctrl+Z restores all 11 positions.
- **Edit by instruction (48D, mocked):** shows the diff in code and on the canvas; Accept applies it and Undo reverts it.
- **Review (48E, mocked):** In short, SPOF, Missing and STRIDE with High/Med badges, the Docs and Flashcards tabs, and Make tasks.
- **Paste detection bar (46J):** "Looks like a Mermaid flowchart… Keep as text / Convert".
- **Insert existing object (48G), version compare (48I) and collapsed group "7 inside ›" (47A):** all present.
- **Chooser (46A):** layout matches.
- **Paper theme (46D):** matches.
- **Phone long-press menu (46Q):** contents match the design while the finger is down.
