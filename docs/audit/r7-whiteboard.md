# Round 7 audit: whiteboard and Board (frames 33–41, 44, 45, 50–52)

Stage 1 of `docs/ROUND7_TODO.md`. This is a read-only comparison of the running app (http://localhost:5330/?demo=1, offline demo) with the frame PNGs in `design/handoffs/2026-11-20-round-7/frames/` and `index.json`.

- **App screenshots:** `design/verify/r7/audit/whiteboard/<ID>-app.png`. Extra states use a suffix, for example `34D-eraser`, `40Dp` (the card picker before the crash), `44I-more`, `33F-touch` and `35A-later`.
- **How the app was driven:** puppeteer-core + Edge, a real mouse and touchscreen, 1440×900 or 412×915. Theme was set through `lumen.settings.theme`, and demo data was reset before each run.
- **Demo data:** the demo whiteboard is "Study plan — November" (1 frame, "Week 3"). The design uses "Week 3 · Optics" (5 frames). Differences that come only from this content are not counted.

Severity: **blocker** = a flow crashes or can't be completed · **major** = a visible feature or state is missing or broken · **minor** = layout, state or copy differs · **polish** = small visual detail.
