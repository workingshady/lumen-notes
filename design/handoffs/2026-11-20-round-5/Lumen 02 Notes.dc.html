Linear algebra: eigenvectors

An eigenvector of a square matrix A is a non-zero vector v that A only stretches: Av = λv. The scalar λ is its eigenvalue. Intuitively, eigenvectors are the directions a linear map leaves pointing the same way.1

They show up all over machine learning: PCA keeps the top eigenvectors of the covariance matrix, and the largest stable step size in Gradient descent is bounded by 2 / λmax of the Hessian. #linear-algebra

NoteEigen- is German for “own” or “characteristic” — the vector belongs to the matrix.

Finding them

Rewrite Av = λv as (A − λI)v = 0. A non-zero solution exists only when A − λI is singular, so

det(A − λI) = 0(1)

Solve this characteristic polynomial for each λ, then plug it back in and find the null space of A − λI.

mermaid · flowchart LR
Matrix A det(A − λI) = 0 λ₁ … λₙ null(A − λI) eigenvectors v
TipFor a 2×2 matrix, λ₁ + λ₂ = tr(A) and λ₁λ₂ = det(A). Use them to check your answers.

In code

pythonCopy
import numpy as np A = np.array([[2, 1], [1, 2]]) vals, vecs = np.linalg.eigh(A) print(vals) # [1. 3.]
Warningnp.linalg.eig doesn't sort its output. For symmetric matrices use eigh: faster, real-valued, ascending.

The idafa (إضافة) is a possessive construction: two nouns placed side by side, where the second owns the first. No word for “of” is needed.

The first noun — the mudāf — never takes the definite article and drops its tanwīn. The second — the mudāf ilayhi — is always in the genitive case. So كِتَابُ الطَّالِبِ is simply “the student's book”

Chains can grow: بَابُ بَيْتِ المُعَلِّمِ, the door of the teacher's house. Only the last noun can be definite.
