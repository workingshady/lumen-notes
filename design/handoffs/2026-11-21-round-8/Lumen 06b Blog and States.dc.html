Eigenvectors, the directions a matrix leaves alone

Amir Hakim

An eigenvector of a square matrix A is a non-zero vector v that A only stretches: Av = λv. The scalar λ is its eigenvalue.

Finding them

A non-zero solution of (A − λI)v = 0 exists only when A − λI is singular, so

det(A − λI) = 0
Tip — for 2×2 matrices, λ₁ + λ₂ = tr(A) and λ₁λ₂ = det(A).

In code

pythonCopy
vals, vecs = np.linalg.eigh(A) print(vals) # [1. 3.]

That's the whole trick: find where the determinant vanishes, then solve for the null space.
